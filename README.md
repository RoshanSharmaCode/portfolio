# 💼 Roshan Sharma - Developer Portfolio

A modern, responsive portfolio website showcasing my projects, technical skills, and experience as a **Full Stack Developer** specializing in the **MERN Stack**.

🌐 **Live Demo:** https://portfolio-delta-dusky-99.vercel.app

---

## ✨ Features

- Modern and responsive UI
- Smooth scrolling navigation
- Project showcase with GitHub & live demo links
- Skills categorized by technology
- Downloadable resume
- Contact section with social links
- Optimized for desktop and mobile

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/RoshanSharmaCode/portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
